# Interaction Spec — Motion · Haptic · Voice

모션이 눈에 띄는 것이 아니라 **재질이 실제로 움직였다고 느껴지는 것**이 목표다.

## Motion

| 대상 | duration | token |
|---|---|---|
| 버튼 press | 120–160ms | `motion.press` (140) |
| 칩 · 세그먼트 선택 | 160–200ms | `motion.chip` (180) |
| 화면 전환 | 200–240ms | `motion.screen` (220) |
| 바텀시트 단계 이동 | 240–320ms | `motion.sheet` (280) |
| 경로 재탐색 | 300–450ms | `motion.route` (380) |

easing 공통: `cubic-bezier(.2, .8, .3, 1)`
눌림 스케일 공통: `0.985`

**Reduce Motion**: opacity만, 120ms 이하. 반복 애니메이션 전면 중지.
`frontend/tokens.css`와 `NaviMotion`에 값이 들어 있다.

### 재탐색 시퀀스 — 4단계로 나눠야 이해된다

| 구간 | 시각 | 내용 |
|---|---|---|
| 1 | 0 → 120ms | 기존 경로 fade — 투명도만 낮춘다, 지우지 않는다 |
| 2 | 120 → 240ms | 차단 위치 강조 — 왜 다시 찾는지 먼저 보여준다 |
| 3 | 240 → 400ms | 새 경로 draw — 출발점에서 목적지 방향으로 |
| 4 | 400 → 450ms | 거리 변화 표시 — 숫자는 롤업으로 |

## Haptic — 화면을 보지 않아도 구분되는 어휘

| 사건 | 패턴 | 세기 | 비고 |
|---|---|---|---|
| 10m 후 회전 | 짧게 1회 | light | 회전 직전 한 번만 |
| 장애물 · 통행 제한 접근 | 강하게 2회 | heavy | 가장 강한 패턴. 다른 데 쓰지 않는다 |
| 경로 이탈 | 반복 2회 (0.4s 간격) | medium | 음성 안내와 동시 |
| 재탐색 완료 | 짧게 2회 | light | 새 경로 draw가 끝나는 시점 |
| 도착 | 길게 1 + 짧게 2 | success | 유일하게 길이가 다른 패턴 |
| 버튼 press | 선택 틱 | selection | Primary CTA에만. 목록 행에는 없음 |
| 오류 · 실패 | 짧게 3회 | error | 재탐색 실패 · 경로 없음 |

진동은 **휠체어를 밀면서 주머니 속 기기로도 구분**되어야 한다. 세 패턴 이상을 한 번에 겹치지 않는다.

## Voice — event 기반

| trigger | 발화 |
|---|---|
| 50m 전 | "오십 미터 앞에서 오른쪽으로 갑니다" |
| 10m 전 | "곧 오른쪽입니다" |
| 회전 직전 | "지금 오른쪽" |
| 위험 구간 진입 | "앞 구간은 확인되지 않은 정보입니다" |
| 경로 이탈 | "경로에서 벗어났습니다. 다시 찾을까요?" |
| 재탐색 완료 | "다른 길을 찾았습니다. 사백삼십 미터 길어집니다" |
| 위치 불확실 | "위치가 정확하지 않아 방향 안내를 멈춥니다" |
| 도착 | "도착했습니다" |

### 발화 규칙

- 숫자는 한글로 읽는다 (430m → 사백삼십 미터)
- 한 문장에 정보는 둘까지
- 이전 발화가 끝나기 전 새 발화를 끼워넣지 않는다 — 큐에 넣고 우선순위로 정렬
- 우선순위: 위험 > 회전 > 재탐색 > 진행 상황
- 미검증 고지는 구간 진입마다 반복하지 않는다. **경로당 한 번**
