## 정밀도로지도는 필요한가

결론은 **전면 채택도 전면 기각도 아닌 선택적 채택**입니다.

2023 `경기안양_시범운행지구`는 8.9km 구간이며, WGS84 환산 범위는 대략 `126.92542–126.97589, 37.38293–37.41292`입니다. 현재 Graph bbox `126.91710–126.93719, 37.38646–37.40815`의 동측 일부와 실제로 겹칩니다.

Graph bbox와 교차하는 주요 객체는 다음과 같습니다.

- 보도 polygon 27개
- 횡단보도 polygon 22개
- 자전거 횡단도 polygon 10개
- 콘크리트 연석 계열 33개
- 무단횡단 방지시설 10개
- 임시구조물 2개
- 링크 145개, 노드 129개

따라서 정밀도로지도 벡터는 다음 용도에 가치가 있습니다.

1. OSM에 없는 보도 면과 횡단부 geometry 후보 찾기
2. 횡단보도·교통신호·연석 계열 객체의 위치 QA
3. OSM Edge와 공공 공간객체 간 spatial mapping 품질 평가

다만 다음 값은 만들 수 없습니다.

- 실제 턱 높이
- 휠체어가 통과할 수 있는 유효 보도폭
- 현재 공사·적치물·엘리베이터 중단 상태
- 검증된 휠체어 통과 가능 여부

또한 자료 연도가 2023년이고 자율주행 차량용 도로·도로시설 표현이 중심이므로, 해당 객체를 곧바로 `wheelchair_accessible`, `blocked`, `verified=true`로 승격하지 않습니다. 모든 매핑 결과는 `source=NGII_HDMAP`, `verified=false` 후보로 두고 정사영상 또는 현장 검수 뒤 채택합니다.

## 점군 자료 판단

정밀도로지도 **벡터 14개 레이어는 유지**하지만, 점군은 현재 내려받지 않습니다.

- 현재 질문인 OSM 보행 Graph의 unknown 감소에는 보도·횡단보도 벡터가 먼저 직접 기여합니다.
- 점군은 용량과 처리비용이 크고, 차량 주행면 중심 고도에서 보도 종단경사나 턱 높이를 계산하려면 별도의 보도면 분리·정합·현장 검증이 필요합니다.
- 향후 100~200m 짧은 표본 구간에서 보도면 점군이 실제 제공되는지 확인하고, 현장 측정값과 오차를 검증할 때만 제한적으로 시험합니다.

## 데이터 신뢰 경계

- 공식 원본 또는 WFS 객체라는 사실과 NaVi 접근성 사실의 검증은 별개입니다.
- 현재 확보 자료는 모두 Shared Graph를 자동 변경하지 않습니다.
- 후보 Feature는 `verified=false`로 만들고, Human Review 승인 후에만 Graph enrichment 대상으로 삼습니다.
- 정사영상은 시각 QA 근거이고, 단독으로 장애·턱·경사·통과 가능 여부를 판정하지 않습니다.

## 다운로드 정리 결과

수치지형도/수치지도 9개 도엽과 대표회랑 25cm 정사영상 4개 도엽의 원본 보관을 완료했습니다. 임시 정리 폴더에 있던 수치지형도·DEM 정확 중복 19건과 내부 ZIP 항목이 동일한 XLSX 중복 4건은 기존 원본을 유지하고 정리했습니다. `37612047.tif.irx`는 완성본 TIFF의 앞 19,537,369 bytes와 일치하는 미완료 다운로드 조각으로 확인해 제거했습니다.

남은 작업은 다운로드가 아니라 원본 TIFF의 georeferencing 복원·기준점 RMSE 검증입니다. 검증 전에는 정사영상을 Shared Graph 변경이나 접근성 Hard Constraint에 사용하지 않습니다.

## 실제 자동평가 결과

2026-09-18 대표회랑 자동평가에서 정밀도로지도는 100m context 안에 보도 23개, 횡단보도 22개, 콘크리트 연석 29개를 제공했습니다. 이 중 Graph에 unique 매칭된 객체는 각각 15, 15, 19개였지만 모두 승인 전 후보입니다.

안양시 공공 횡단보도 402개를 교차검증한 결과, HD 횡단보도와 20m 이내 대응은 12개, 20~50m 검토 대상은 6개였습니다. 192개는 시범운행지구 coverage 밖이며, coverage 안 192개는 50m 이내 대응 객체가 없었습니다. 이는 정밀도로지도가 OSM 대체재가 아니라 부분 coverage의 geometry QA 보조자료라는 판단을 뒷받침합니다.

정사영상은 공식 EPSG:5179 extent로 affine sidecar를 복원했고 계산 픽셀 크기 0.250970~0.251553m를 확인했습니다. 다만 독립 기준점 RMSE가 아직 없으므로 visual QA만 `partial_accept`, geometry 자동 수정은 계속 `hold`입니다.
