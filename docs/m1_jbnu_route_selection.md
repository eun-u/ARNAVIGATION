# M1 전북대 내부 PoC 경로 선정 기록

상태: **M1-ALIGN 활성 경로 확정**

선정일: 2026-09-18

용도: M1 AR 리본 공간 정합 3회 검증

이 문서의 25m 단일 Edge는 AR 정합 전용이며 장애물 차단·재탐색·도착 실증 경로가 아니다. 전체 폐루프 실증에는 별도로 선정한 [E2E-WC 전북대 휠체어 가정 재탐색 경로](e2e_wc_jbnu_route.md)를 사용한다.

## 결정

전북대학교 전주캠퍼스 내부의 **106 학생군사교육단 남측 녹지 보행로**를 활성 PoC 경로로 사용한다. OSM way `471373639`의 중앙 25m를 서쪽에서 동쪽으로 진행한다.

- 시작: `127.13143032, 35.84591590`
- 종료: `127.13170667, 35.84590380`
- 길이: `25.0m`
- 방위: `93.09°`
- 로컬 Edge: `LOCAL_OSM_427b2b6f53e0`
- 지도: <https://www.openstreetmap.org/?mlat=35.8459099&mlon=127.1315685#map=19/35.8459099/127.1315685>

기존 정문 주변 구간은 활성 시험 경로에서 제외한다. 이전 산출물은 이력 확인용 로컬 파일로만 남기며 공용 Graph에는 어느 구간도 반영하지 않는다.

## 선정 기준

“가장 효율적”은 현장 3회를 짧고 동일하게 반복하면서 AR 정합에 불필요한 변수가 적다는 뜻으로 정의했다. 캠퍼스 전체 보행망 후보에 다음 기준을 적용했다.

1. 캠퍼스 경계 안쪽의 `highway=footway`일 것
2. 계단·횡단·실내·사유지·허가제·보행 금지 태그가 없을 것
3. 25m 구간 직선성 `0.995` 이상일 것
4. 원 보행선 양끝에 각각 15m 이상 준비·종료 여유가 있을 것
5. 차량 통행선에서 20m 이상, 계단·횡단 구간에서 15m 이상 떨어질 것
6. 건물에서 8~35m 떨어져 하늘 노출과 AR 시각 특징의 균형을 가질 것
7. 캠퍼스 외곽 경계에서 100m 이상 안쪽일 것

최종 구간의 데스크톱 OSM 형상 지표는 다음과 같다.

| 지표 | 결과 |
|---|---:|
| OSM 원 보행선 길이 | `75.031m` |
| 시작 전 / 종료 후 여유 | `25.015m / 25.016m` |
| 25m 직선성 | `1.000` |
| 차량 통행선 이격 | 약 `22.8m` |
| 계단·횡단 이격 | 약 `19.6m` |
| 최근접 건물 이격 | 약 `11.1m` |
| 캠퍼스 경계 안쪽 깊이 | 약 `215.9m` |

이격값은 2026-09-18 OSM 객체와 캠퍼스 경계를 투영해 계산한 사전 선별값이다. 현장 상태나 안전을 증명하지 않는다.

## 비교에서 제외한 대표 후보

| 후보 | 장점 | 제외 이유 |
|---|---|---|
| 대학본부 인접 보행로 | 직선, 차량 도로와 약 39.7m 이격 | 건물과 약 2.2m로 너무 가까워 GPS 다중경로·하늘 가림 위험이 큼 |
| 공과대학 1·4호관 사이 | 찾기 쉽고 차량 도로와 멂 | 원 보행선이 약 30.1m뿐이라 25m 시험 전후 여유가 약 2.6m에 불과 |
| 중앙 북측 장거리 보행로 | 원 보행선이 길고 캠퍼스 안쪽 | 25m 직선성이 약 `0.981`로 첫 기준선 시험에 불필요한 곡률이 있음 |

## 안전·데이터 경계

- 현장 도착 후 보행로 연속성, 공사, 차량 진출입, 혼잡, 노면을 먼저 확인한다.
- 사전 지표와 현장이 다르면 시험을 중단하고 문서의 좌표를 임의로 바꾸지 않는다.
- 턱·폭·경사·표면·휠체어 통행 가능성은 모두 `unknown`, `verified=false`다.
- 결과는 `field_test_only=true`이며 공용 Graph 자동 반영과 자동 재탐색에 사용하지 않는다.

공식 캠퍼스 위치와 랜드마크 대조에는 [전북대학교 캠퍼스 지도](https://www.jbnu.ac.kr/web/intro/campus/sub02.do)를 사용했고, 경로 형상은 [OpenStreetMap](https://www.openstreetmap.org/way/471373639)을 사용했다.
