# NaVi 모바일 프론트 유즈케이스

## UC-01 경로 계획

- **사용자:** 휠체어 또는 개인 이동 보조기기 사용자
- **사전 조건:** 앱이 그래프 API 또는 데모 그래프를 불러옴
- **기본 흐름:** 출발지와 목적지를 선택하고 이동 조건 프리셋을 확인한 뒤 `접근 가능한 경로 찾기`를 누른다.
- **결과:** 일반 경로와 접근 가능 경로가 계산되고 경로 결과 화면으로 이동한다.
- **예외:** API 실패 시 데모 모드로 전환하며 전환 사실을 지속 표시한다.

## UC-02 경로 비교

- **기본 흐름:** 사용자는 지도에서 접근 가능 경로와 일반 경로를 비교한다.
- **표시 정보:** 거리, 예상 시간, 추가 이동 거리, 검증 상태, 제외 사유.
- **완료 조건:** 경로 차이가 숫자와 지도 선형, 텍스트 이유로 모두 구분된다.

## UC-03 판단 근거 확인

- **기본 흐름:** `왜 이 경로인가요?`를 선택해 제외된 계단·차단 구간과 데이터 출처를 확인한다.
- **결과:** 사용자는 정보가 OSM, manual, public data, synthetic 중 어디에서 왔고 검증됐는지 알 수 있다.
- **예외:** 근거가 없으면 `확인 가능한 세부 근거 없음`으로 표시하고 사실을 생성하지 않는다.

## UC-04 카메라 AR 안내

- **기본 흐름:** 카메라 권한을 허용하고 다음 행동, 방향, 남은 거리, 이동 조건을 확인한다.
- **권한 거부:** 정적인 AR 시뮬레이션과 지도 복귀 버튼을 제공한다.
- **완료 조건:** 카메라 연결 여부와 영상 분석 시뮬레이션 여부가 동시에 명확하다.

## UC-05 장애물 발생과 재탐색

- **기본 흐름:** 데모 장애물 입력 → 현재 세션 Edge 임시 차단 → 접근 경로 재계산 → 변경 전·후 거리와 방향 표시.
- **복구:** 같은 버튼으로 시연 상태를 초기화할 수 있다.
- **완료 조건:** 재탐색 전후 경로와 추가 이동 거리가 화면에서 비교된다.

## UC-06 현장 상태 제보

- **기본 흐름:** 유형 선택, 선택 사진, 메모를 입력하고 임시 저장한다.
- **현재 PoC:** 별도 시민 제보 API가 없으므로 브라우저 기기에만 저장한다.
- **신뢰 경계:** `검수 전 경로 미반영`, `기기 임시 저장`을 완료 화면에 표시한다.

## UC-07 사람 검수

- **사용자:** 검수 담당자
- **기본 흐름:** 후보 선택 → 외부 근거 확인 → 판정·관찰시각·사유 입력 → 승인/기각/추가 근거 요청.
- **결과:** approved 상태만 verified observation으로 변환될 수 있다.
- **안전 조건:** AI 문구를 검수 근거로 자동 복사하지 않는다.
