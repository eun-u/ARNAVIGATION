절대 규칙

① 앱은 사용자의 Hard Constraint를 임의로 완화하지 않는다. 완화는 항상 사용자가 명시적으로 고른다.

② "경로를 찾을 수 없습니다"라는 문장은 쓰지 않는다. 무엇이 막았는지를 말한다.

③ 모든 실패 상태에는 최소 2개 이상의 다음 행동이 있어야 한다. 막다른 화면을 만들지 않는다.
