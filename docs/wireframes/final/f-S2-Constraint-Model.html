요청 스키마
POST /route
{
  "origin": [...],
  "destination": [...],
  "constraints": [
    {"type":"has_stairs",
     "op":"==","value":false,
     "priority":"hard"},
    {"type":"curb_height",
     "op":"<=","value":2,
     "unit":"cm",
     "priority":"hard"}
  ],
  "allow_unknown": false
}
구현 시 확인할 것

· UI 슬라이더 눈금과 value 단위가 같은가
· hard가 하나라도 위반되면 edge를 완전히 제외하는가 (가중치 증가가 아니라)
· 제보로 만든 blocked가 공용 Graph에 새지 않는가
· allow_unknown이 세션 종료와 함께 초기화되는가
